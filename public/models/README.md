# Model logos

The "How it works" animation looks here for a logo for each small model and
falls back to a letter badge when a file is missing.

Expected file names (SVG preferred, PNG also works, square artwork):

- `qwen.svg`
- `modernbert.svg`
- `gemma.svg`

To change which models appear, edit `TASKS` in `src/components/workflow-scene.ts`.
